# Optional delegation

Use only an actual authorized host capability. A skill name or installed dispatch file doesn't establish that an agent can be spawned. If unavailable, do a disclosed single-agent audit. Do not launch children just to prove the protocol or improve a metric.

Delegate a coherent boundary or question. Supply actual snapshot, intent and exclusions, available evidence, permissions and the specific unknown. A discovery reviewer gets a neutral objective, not a leading list of desired bugs. A finding verifier gets the claim and counterevidence. Necessary context must not be withheld in the name of independence.

Ask for consequential findings, their evidence, uncertainties and examined scope, not line references for every passed criterion. Allow cheap targeted source re-reads to locate evidence rather than making a model count diff lines. Returned claims need reconciliation against actual execution. Requested model and observed model are different facts; missing identity stays unknown.

One coordinator combines findings and owns state. Review disagreement is resolved by a distinguishing fact/probe or retained uncertainty, not majority vote. No fixed reviewer count and no repeated review until clean.
