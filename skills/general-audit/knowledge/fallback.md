# Local fallback

If the library lacks a boundary, continue investigation rather than first expanding the global skill. Retain useful selected cards. State the intended outcome/authority, actual owners and consumers, plausible reachable failure, smallest distinguishing evidence, counterexample and what remains unknown.

Inspect project code/configuration and primary documentation for the actual version. A new framework name is not a reason to import its entire tutorial. If evidence is unavailable, preserve a precisely bounded gap instead of borrowing a similar technology's guarantees. Workload and supported consumers define relevance, not generic best practices.
