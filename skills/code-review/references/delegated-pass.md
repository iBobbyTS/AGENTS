# Delegated bounded review

`context=DELEGATED_PASS`; this reference is the single-pass method. Plain Markdown is valid; no JSON registry, signed receipt or matching-hash approval is required.

Parent owns scope, admission, repair assignments, budgets, provider selection, acceptance and integration. Return one signal: CLEAN, MATERIAL_CANDIDATES or INSUFFICIENT_EVIDENCE. CLEAN covers only the requested range and checks, not automatic acceptance or implementation permission.

## Scope

INITIAL_BOUNDED and FINAL_BOUNDED inspect the specified complete parent base→candidate and its direct impact cone. REPAIR_DELTA inspects frozen findings, repair diff and invalidated coverage only. SUBSECTION_DELTA includes new child implementation and parent invariants, safe intermediate state and planned consumer. Unimplemented later behavior is not a defect unless this checkpoint falsely exposes it or violates an existing invariant. PARENT_RECONCILIATION completes reconciliation coverage on the final parent: cross-child interactions, changed prior paths, real consumer and joint oracles. INTEGRATION covers emergent cross-section/runtime/process composition on the integrated feature when the packet names a non-empty `unproven_composition`. Local green checkpoints alone are not proof.

## Causality

Each material candidate names changed-code cause, supported reachable trigger, prior authority, consequence and smallest bounded repair. A candidate blocks only as DIFF_CAUSED, a tightly proven MERGE_BLOCKING_DEPENDENCY, or an EVIDENCE_GAP anchored to an existing acceptance criterion; NIT_DEBT, new guarantees, unrelated old defects and speculative guarantees are non-blocking. Inspect dependencies only along the causal path. Missing candidate stability or required evidence yields INSUFFICIENT_EVIDENCE, not invented CLEAN.

Never forward this pass to another reviewer or transport, and never relabel a result as another provider's. The shared skill name is methodology, not transport identity. Apply the curated task constraints and this self-contained role instruction. No edits, repairs, commits or delegation.

## Return

Include pass/parent/child IDs from the packet, coverage, checks reused/run/gaps, candidate proof, pending behavior and relevant checkpoint invalidations. Successful runtime exit or a valid artifact hash is not a semantic CLEAN. Only main decides the next allowed unit.
